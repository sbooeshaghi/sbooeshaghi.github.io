Long-read sequencing transcriptome quantification with lr-kallisto

Long-read RNA sequencing can clarify transcript isoforms, but transcriptome-scale quantification still needs methods that are both accurate and computationally efficient. Existing long-read tools can be slower or more memory intensive, and enrichment strategies such as exome capture need quantitative evaluation. lr-kallisto provides accurate ONT transcript quantification, benefits from exome capture, and uses less runtime and memory than alternative long-read methods.
