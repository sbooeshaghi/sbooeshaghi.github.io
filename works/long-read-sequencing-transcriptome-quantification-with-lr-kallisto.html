Long-read sequencing transcriptome quantification with lr-kallisto

Long-read RNA sequencing can clarify transcript isoforms, but transcriptome-scale quantification still needs methods that are both accurate and computationally efficient. Existing long-read tools can be slower or more memory intensive, and enrichment strategies such as exome capture need quantitative evaluation. lr-kallisto adapts kallisto pseudoalignment for long reads and demonstrates accurate ONT quantification, improved performance with exome capture, and lower runtime and memory use.
