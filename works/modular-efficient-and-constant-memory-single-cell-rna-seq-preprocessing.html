Modular, efficient and constant-memory single-cell RNA-seq preprocessing

Versions
Modular, efficient and constant-memory single-cell RNA-seq preprocessing Nature Biotechnology · 2021-04-01

Summary

State-of-the-art tools for single-cell RNA-sequencing preprocessing are memory intensive and slow; requiring upwards of 100GB of RAM and up to a day of processing time for a standard experiment (~10k cells, ~600 million reads). These resource requirements translate to high costs and excessive wait time. To address this, we developed the kallisto bustools workflow for single-cell RNA-sequencing preprocessing. Our workflow outperforms state-of-the-art tools with speed improvements of up to 50x and memory improvements up to 9x with minimal accuracy tradeoffs. The kallisto bustools workflow has been cited 199 times and has been used for a number of large projects.
