Modular, efficient and constant-memory single-cell RNA-seq preprocessing

Single-cell RNA-seq preprocessing determines whether large assays can be analyzed accurately and affordably. Growing datasets expose bottlenecks in memory, speed, and workflow flexibility, especially when users need downstream analyses such as RNA velocity. The kallisto-bustools workflow uses BUS-based modular preprocessing to achieve near-optimal speed, constant memory, Cell Ranger-concordant counts, and scalable RNA velocity analysis.
