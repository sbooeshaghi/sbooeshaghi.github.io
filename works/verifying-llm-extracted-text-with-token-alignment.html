Verifying LLM-extracted text with token alignment

LLMs can extract useful text from documents, but scientific reuse requires knowing whether an extracted passage is actually supported by the source. Verification is difficult when answers combine non-contiguous phrases or when token boundaries do not match words. Ordered subword alignment benchmarks and the taln implementation demonstrate that LLM-extracted text can be checked deterministically against source documents without relying on semantic judgment.
