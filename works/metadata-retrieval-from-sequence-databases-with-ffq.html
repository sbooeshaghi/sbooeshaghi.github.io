Metadata retrieval from sequence databases with ffq

Public sequencing data are increasingly reused with new experiments, making metadata collation and raw-data acquisition essential. Existing metadata tools cover a limited set of databases, while user-uploaded sequencing metadata have little standardization. Ffq exploits shared database hierarchies to retrieve accession- or DOI-associated metadata and raw-data links as JSON and can extend to genomic databases with programmatic access.
