Metadata retrieval from sequence databases with ffq

Public sequencing archives are increasingly reused for new analyses, making metadata retrieval and raw-data link discovery part of practical genomics work. Existing tools tend to cover limited repositories, and user-submitted metadata remains uneven and difficult to standardize. ffq exploits common database hierarchies and public APIs to return accession- or DOI-derived metadata and data links as JSON, enabling lightweight command-line parsing and streamwise downstream processing.
