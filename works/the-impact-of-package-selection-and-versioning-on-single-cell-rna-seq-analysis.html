The impact of package selection and versioning on single-cell RNA-seq analysis

Single-cell RNA-seq workflows shape biological interpretation, so reproducible package behavior matters when analyses pass through many algorithmic steps. Widely used tools are often treated as interchangeable, but Seurat/Scanpy choices and version changes can alter outputs from feature selection through differential expression. By comparing package and version effects across the standard pipeline, the article establishes metrics for assessing those differences.
