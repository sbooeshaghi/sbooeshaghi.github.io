The impact of package selection and versioning on single-cell RNA-seq analysis

Cell Systems 2026-04 bioRxiv 2024-04-05

Summary

Single-cell RNA-seq analysis depends on rapidly changing software packages and package versions. This study evaluates how those choices can affect downstream analysis results, emphasizing the need to track computational environments and compare workflows carefully.
