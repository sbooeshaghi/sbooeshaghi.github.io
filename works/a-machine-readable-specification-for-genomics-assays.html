A machine-readable specification for genomics assays

Accurate preprocessing of genomics reads depends on knowing how biological and technical sequences are arranged in each library. Assay-specific scripts, divergent parameters, absent sequence annotations, and non-machine-readable library descriptions make uniform processing, comparison, and reanalysis difficult. Seqspec provides a YAML-based library specification and command-line tool that validates assay descriptions and generates technology strings for preprocessing tools.
